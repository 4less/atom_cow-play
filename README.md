# atom_cow: play in the browser

**Play: https://4less.github.io/atom_cow-play/**

On a phone: open the link, turn the phone sideways, tap *Fullscreen* in the menu.
For a real app feel, use *Add to Home screen* (Android Chrome / iPhone Safari): it then starts fullscreen in landscape.

This repo only holds the built game (Godot web export); it is overwritten on every publish.
Fighter sprites: LuizMelo (CC0). Font: Silkscreen (OFL).
